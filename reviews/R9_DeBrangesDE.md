## 2. Theorem D: proof-plan audit

1. **Dominated half-plane Cauchy–Goursat theorem (§1.3).**
   * *Vertical sides via Tonelli:* `∫⁻_x ∫⁻_{(0,Y]} |F(x+iy)|² ≤ YC`, so `H(x) + H(-x) ≤ 1` for
     arbitrarily large `x`. With `d ≥ R - ‖w₀‖ =: ρ`, the side integral of `G` is at most
     `(1+2Y)/(2ρ) + 2Y|A|/ρ²`, which tends to 0 (recomputed).
   * *Rectangle:* the orientation and the `re`/`im` simp lemmas match Mathlib's
     `integral_boundary_rect_eq_zero_of_differentiable_on_off_countable` (signature checked).
   * *Top side:* the `ε`-AM–GM bound gives `‖∫G(·+iY)‖ ≤ (ε/2)C + (1/(2ε)+|A|)π/(Y-b)`, and the choice of
     `ε, Y` makes this `< η`.
   * One `toReal` step needs care: F1.
2. **Cauchy formulas.**
   * *Upper and lower:* `integral_cauchy_pair` gives `2ib·π/b = 2πi`.
   * *Real point:* with `c = x - i`, `x - c = i` and `t - c = t - x + i`, so `dslope Φ x t` is exactly the
     displayed integrand for `t ≠ x`.
   * *Poisson:* `(t-w)⁻¹ - (t-w̄)⁻¹ = 2ib/((t-a)²+b²)`.
   * *Line bound:* Cauchy–Schwarz against a probability kernel, then Tonelli.
   * All verified (numerics 2).
3. **`K_w ∈ H(E)`.**
   * `K_w/E = (i/2π)(conj E(w) - Θ conj E^*(w))/(z - w̄)` with `|Θ| ≤ 1` on `ℂ₊`.
   * For `Im w > 0` the near region of the decay criterion is empty (`r = Im w`).
   * Otherwise `E(w̄) ≠ 0` gives local boundedness.
   * `K_w^* = K_{w̄}` handles `f^*/E`.
4. **Reproducing property.**
   * *`ℂ₊` and `ℂ₋`:* `integrand_eq` splits the integrand into an `A`-part (`cauchy_upper` or
     `integral_div_lower`) and a `conj B`-part (the conjugate of the other formula at `w̄`). This gives
     `(-i/2π)·2πi f(w) = f(w)`; in the lower case it uses `E^*(w) = conj E(w̄) ≠ 0`.
   * *Real `x`:* by `integrand_eq_real`, the `ψ - conj ψ` terms cancel exactly against
     `f(x)·2i/((t-x)²+1)`, and `E(x)A(x) = E^*(x)conj g(x) = f(x)`. Verified symbolically and numerically.
   * No limiting argument in `w` is needed.

## 3. Theorem E: proof-plan audit

* **Orthogonality.**
  * `K(γ,z)π(z-γ) = -C(γ)S(z)` and `S(γ') = 0` give orthogonality.
  * `‖K_γ‖² = K(γ,γ) = φ'|E|²/π = 1/wt`.
  * `S'(γ) = -C(γ)φ'(γ) ≠ 0`, because `C(γ)² = |E(γ)|² > 0`. So the zeros of `S` are simple.
* **Bessel** follows from `0 ≤ ‖f - s_F‖²` with `‖s_F‖² = ⟨f,s_F⟩ = Σ_F wt|f(γ)|²`.
* **Completeness of `H(E)`.**
  * The evaluation bound `|f(z)|² ≤ K(z,z)‖f‖²`, together with the local bound of `K`, makes the sequence
    uniformly Cauchy on balls. The limit is entire (`TendstoLocallyUniformlyOn.differentiableOn`).
  * Fatou gives norm convergence.
  * Fatou plus `MemHE.lintegral_line_le`, which comes from the Poisson formula, bounds the lines of
    `g/E` and `g^*/E`.
* **Mittag-Leffler.**
  * Bessel for `K_i` gives `Σ c_γ/(1+γ²) < ∞`.
  * For `|γ| ≥ 2ρ+1` the M-test bound `2M(1+ρ)c_γ/(1+γ²)` holds, so `R` is entire.
  * `D(γ) = C(γ) + π·c_γ·S'(γ) = C(γ) - C(γ) = 0`.
  * `h = D/S` is entire and real (both branches of the blueprint's `if` definition commute with `conj`).
* **Defect identity.** Recomputed:
  * `kernel_mul_CS` gives `(I/2)(-2iC s̄ + 2iS c̄) = C s̄ - S c̄`.
  * `term_identity` follows from the bracket identity above.
  * Hence `Qπ(z-w̄) = conj S(w)D(z) - S(z)conj D(w) = S(z)conj S(w)(h(z) - conj h(w))`.
* **`Im h ≥ 0`.** `Q(w,w) ≥ 0` is Bessel for `K_w`; a simpler derivation is given in F2.
* **Entire Pick lemma.**
  * The two Poisson formulas give `v(w)/Im w = 2⨍ k_w m` with `m = Im ζ·v(ζ) ≥ 0`.
  * The kernel comparison with `κ(r,R) → 1` gives `v(w)/Im w` constant, so `h - pz` is real-valued, hence
    constant.
* **`p > 0 ⇒ S ∈ H(E)`.** `Q_i ∈ H(E)` and `Q_i = (p/π)conj S(i)·S` off `{-i}`. Continuity and
  `S(i) ≠ 0` give `S = κ⁻¹Q_i`.
* **Conclusion.**
  * When `p = 0`: `‖Q_w‖² = Q(w,w) = 0` for nonreal `w`, so `f(w) = ⟨f,Q_w⟩ = 0`, and continuity gives
    the real points.
  * The norm identity follows from `f = Σ f(γ)wt(γ)K_γ`.
  * The `ℝ≥0∞` conversion uses `ENNReal.ofReal_tsum_of_nonneg`.

## 4. Examples recomputed

* **`E = e^{-iπz}`.**
  * `φ = πx`, `K(w,z) = sin π(z-w̄)/(π(z-w̄))`.
  * `α = 0`: `C = cos πz`, `S = -sin πz`, `Γ = ℤ`, `c_γ = 1/π²`, `wt = 1`.
  * `(1+γz)/((1+γ²)(z-γ)) = 1/(z-γ) + γ/(1+γ²)`, and `Σ_ℤ` of this is `π cot πz`. Hence `R = -C/π`,
    `D = 0`, `h = 0`.
  * `α = π/2`: `C = sin πz`, `S = cos πz`, `Γ = ℤ + 1/2`, `Σ = -π tan πz`, again `R = -C/π`.
  * `kernel_mul_CS` reads `sin π(z-w̄) = sin πz cos πw̄ - cos πz sin πw̄`.
  * `summable_cLev_dslope_sq` at `z = i` holds with equality: `(sinh²π/π²)·π coth π = sinh 2π/(2π) = K(i,i)`.
* **`E = z + i`.**
  * `φ = arctan x - π/2 ∈ (-π, 0)`, `φ' = 1/(1+x²)`, `K ≡ 1/π`, `H(E) = ℂ`, `‖1‖² = π`.
  * `α = 0`: `S = 1`, `C = z`, `Γ = ∅`, `h = z`, `p = 1`, `Q = K = 1/π = (p/π)S conj S`.
  * `α = -π/2`: `S = -z`, `C = 1`, `Γ = {0}`, `c₀ = 1/π`, `R = -1/π`, `D = 0`; Theorem E reads
    `π = wt(0)·1`.
  * General `α` with `sin α ≠ 0`: `S = z sin α + cos α`, `Γ = {-cot α}`, `R = (1+γz)sin α/π`, and again
    `D = 0`.
* All the blueprint's claims about these examples are correct.

**O1 (observation, not a defect).** For `E = e^{-iπz}` and generic `α` (`Γ = ℤ + α/π`), `R ≠ -C/π`:
`h ≡ κ_β/π` is a nonzero **real constant**. Here `κ_β` is the symmetric sum `Σ γ/(1+γ²)` over the
asymmetric `Γ`. Numerically `h ≈ 0.00212` for `α = 0.3` and `h ≈ -0.00301` for `α = -1.1`. So `p = 0` and
`Q = 0`, as the theory says. The blueprint names only `α = 0, π/2`, where `q = 0`, so it is correct.
Implementers should not expect `D ≡ 0` in general; only `p = 0` is used.

## 7. Findings

**F1 [minor] `integral_eq_integral_line_of_sides`: the `toReal` step needs eventual finiteness.**
*Evidence.* §1.3 bounds `‖Vₙ⁺‖ + ‖Vₙ⁻‖` by `(∫⁻_{(0,Y]}(‖G(R+iy)‖ₑ + ‖G(-R+iy)‖ₑ)).toReal`. That inequality
fails when the lintegral is `∞` (its `toReal` is `0`), and `hside` only makes it finite *eventually*.
*Fix.* Stay in `‖·‖ₑ`:
* `‖I•V⁺ - I•V⁻‖ₑ ≤ ‖V⁺‖ₑ + ‖V⁻‖ₑ ≤ ∫⁻(…)` by `enorm_integral_le_lintegral_enorm` and
  `le_lintegral_add`;
* conclude `Tendsto (fun n ↦ I•V⁺ₙ - I•V⁻ₙ) atTop (𝓝 0)` with `tendsto_iff_enorm`-style lemmas, or with
  `ENNReal.tendsto_toReal` after `hside.eventually (lt_mem_nhds …)`.

The blueprint's parenthetical "alternatively `enorm_integral_le_lintegral_enorm` directly" is the right
route; make it the main one.

**F2 [minor] `im_hFun_nonneg`: an easier derivation that avoids proving `Q(w,w)` real.**
Take imaginary parts of `defectKer_mul D hh w w`. The left side is `Q·π·(w - w̄) = Q·2πi·Im w`, whose
imaginary part is `2π·Im w·Re Q(w,w)`. The right side is `‖S w‖²·(h w - conj h w) = ‖S w‖²·2i·Im h(w)`,
whose imaginary part is `2‖S w‖²·Im h(w)`. Hence `Im h(w) = π·Im w·Re Q(w,w)/‖S w‖² ≥ 0`, by
`defectKer_diag_nonneg` and `sFun_ne_zero`. This needs neither `Complex.im_tsum` nor reality of `K(w,w)`.
The blueprint's route ("`Q(w,w)` is real") is correct but longer.
