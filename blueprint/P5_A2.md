# P5 finite weighted tests and A2: proposed interfaces

Owner: `sol_pavlov_weights`. Date: 2026-11-07. The signatures below are proof plans, not assumptions.

The target weight is `w x = ‖d.G ((x : ℂ) + (ε : ℂ) * Complex.I)‖ ^ 2`.
The discrete weights are `v k = ‖deriv d.G (g.point k : ℂ)‖ ^ 2 > 0`.
No change to `Defs`, no Pavlov hypothesis, and no import of `Unconditional` is required.

## Independent finite algebra

`Weights.lean` imports `Cardinal` and adds finite-sum lemmas in `FF.Pavlov`.
For arbitrary finite index sets define `weightSum s v = ∑ k ∈ s, v k` and
`invWeightSum s v = ∑ k ∈ s, (v k)⁻¹`. Prove:

* Positive weights imply `(s.card : ℝ)^2 ≤ weightSum s v * invWeightSum s v`.
  Use the finite Cauchy inequality with summand `1`, and `v k * (v k)⁻¹ = 1`.
* If `WJ * VI ≤ K`, `WI * VJ ≤ K`, and `0 < n² ≤ WJ * VJ`,
  then `WI * VI ≤ K² / n²`. All four sums are nonnegative.
  This is multiplication of the two estimates and cancellation of a positive factor.
* A positive-kernel matrix bound yields the cross estimate. For a real matrix `T`,
  positive weights on nonempty `s`, `t`, and `0 < κ`, assume `κ ≤ T j k` for
  `j ∈ t`, `k ∈ s` and
  `∑ j ∈ t, v j * (∑ k ∈ s, T j k / v k)^2 ≤ C * invWeightSum s v`.
  Then `weightSum t v * invWeightSum s v ≤ C / κ²`.
  This only needs positivity, finite sum monotonicity, and cancellation of `VI > 0`.

These statements deliberately do not assume distinct/disjoint blocks: those are needed only when proving
kernel positivity from the geometric locations. They were implemented after review independently of Grid.

## Analytic matrix input

Required dependencies: `GeneratingData.cardinal_synthesis_bound`, `Grid`, cell bounds from Harnack,
real `plancherelPolya`, and a PW horizontal translation bound. For finite source and target subsets of ℤ,
prove (for one fixed `ε > 0`):

```
∑ j ∈ t, v j * ‖∑ k ∈ s, (b k : ℂ) /
  ((g.point j : ℂ) + ε * Complex.I - g.point k)‖^2
  ≤ C * ∑ k ∈ s, v k * ‖b k‖^2.
```

Apply cardinal synthesis with coefficients `a k = b k * deriv d.G (g.point k)`.
Its value at the shifted target is `G(z) * ∑ b k / (z-g.point k)`.
The lower node comparison `‖G(γj+iε)‖² ≥ c v j` supplies the left side.
The shifted sampling estimate supplies the uniform C. Finite sets avoid an extra infinite-sum conversion.

For a consecutive source block of N indices and a translated target block of N indices separated by N indices,
Grid gaps give `a N ≤ γj-γk ≤ b N`. Thus the real part of the Cauchy kernel lies between
`c/N` and `C/N`, with c depending on lower/upper gaps and ε. On reversing the blocks negate the real part.
Use `b k = 1/v k` on the source. The preceding finite lemma yields both cross estimates `≤ C N²`.
Cauchy on the target block yields diagonal discrete A2 `WI * VI ≤ C² N²`.

## Continuous transfer

The Harnack cell comparison yields uniform `c v k ≤ w x ≤ C v k` on cell k.
Cell lengths lie in `[q,D]`. For intervals of length at least q, enlarge to the union of intersecting cells;
its number of cells is at most `2 + |I|/q ≤ 3 |I|/q`. Bound both integrals by the corresponding finite
weight sums times `D`, then use discrete A2. For intervals shorter than q, they meet at most two cell
interiors (three endpoint cells cause no integral contribution). Adjacent weights must first be uniformly
comparable: continuity of w and its two closed-cell comparisons at the shared endpoint gives
`v (k+1) / v k ≤ C/c` and its reverse. This supplies a uniform local ratio for short intervals.
This endpoint comparison is necessary; discrete A2 alone does not control subcell intervals without it.

The final helper will state existence of ε and A with positive ε,A, local integrability of w and w⁻¹,
and `(∫ x in a..b, w x) * (∫ x in a..b, (w x)⁻¹) ≤ A * (b-a)^2` for `a < b`.
Continuity and the generator zero set imply both local integrability statements for every positive ε.
The subsequent logarithm/BMO module consumes this result.

## Completed continuous transfer

`Weights.lean` now exports `CardinalData.discrete_A2`, with only `d : CardinalData Γ`, `g : Grid Γ`,
and `hΓ : IsSeparated Γ` as inputs. Its uniform bound is on every `g.block a N`, `a : ℤ`, `N : ℕ`, `0<N`.
There is no auxiliary shifted comparison hypothesis in this theorem.

`WeightTransfer.lean` imports `Weights` and `LogDistanceLarge`. The latter provides the independent geometry
lemma `Grid.exists_cell_cover`: an interval of length L is covered by a consecutive cell block of cardinality
at most `L/g.lower + 2`. The main transfer estimate uses an effective length `min g.upper L`.
For a nonnegative upper bound `w≤v_k` on each cell, integrating the finite sum of cell indicators gives
`∫_I w≤g.upper*Σv_k`; the pointwise bound by `Σv_k` gives `∫_I w≤L*Σv_k`.
Thus both inequalities hold with their minimum. Reciprocal weights satisfy the same bound.

The product estimate and discrete A2 leave the numerical factor `min(D,L)^2*N^2`.
If `L≥q`, use `N≤3L/q` and `min(D,L)≤D`. If `L≤q`, use `N≤3` and `min(D,L)≤L`.
Since `q≤D`, both cases give `min(D,L)*N≤(3D/q)*L`.
This handles short intervals directly: a separate adjacent-weight lemma is unnecessary because the two-cell
discrete A2 bound already controls the ratio of those weights. The earlier adjacency discussion is an
alternative proof, not a remaining dependency.

The final proved interface is:

```lean
theorem CardinalData.shifted_A2 {Γ : Set ℝ} (d : CardinalData Γ)
    (g : Grid Γ) (hΓ : IsSeparated Γ) :
    ∃ ε K : ℝ, 0 < ε ∧ ε < g.lower/8 ∧ 0 < K ∧
      LocallyIntegrable (fun x : ℝ ↦ ‖d.G ((x : ℂ)+(ε : ℂ)*I)‖^2) ∧
      LocallyIntegrable (fun x : ℝ ↦ (‖d.G ((x : ℂ)+(ε : ℂ)*I)‖^2)⁻¹) ∧
      (∀ x : ℝ, 0 < ‖d.G ((x : ℂ)+(ε : ℂ)*I)‖^2) ∧
      ∀ a b : ℝ, a < b →
        intervalMean (fun x : ℝ ↦ ‖d.G ((x : ℂ)+(ε : ℂ)*I)‖^2) a b *
          intervalMean (fun x : ℝ ↦ (‖d.G ((x : ℂ)+(ε : ℂ)*I)‖^2)⁻¹) a b ≤ K
```

Positivity follows from the cell comparison and simplicity of the generator zeros. The weight and reciprocal
are continuous on ℝ, hence locally integrable. The interval-mean normalization is exactly `FF.intervalMean`.
All proofs are in Lean; there are no new axioms, `sorry`, definition changes, or linter suppressions.

For coordination with the real-boundary logarithm step, there is also the fixed-height theorem
`CardinalData.shifted_A2_of_bounds d g hΓ ε c C hc hC hbounds`. Its `hbounds` is exactly the pair of shifted
norm inequalities on each closed cell; it returns K, local integrability, positivity, and the same mean A2 bound
at that particular ε. Thus a caller can obtain `generating_cell_bounds` once, retain both shifted and real
bounds, and use a single ε in both A2 and the logarithmic comparison. Independently existential ε values need
not be identified. `shifted_A2` is the short existence wrapper around this helper.

## Completed boundary logarithm bridge

`BoundaryWeight.lean` imports `WeightTransfer` and `LogDistance` and proves:

```lean
theorem CardinalData.boundary_log_bmo {Γ : Set ℝ} (d : CardinalData Γ)
    (g : Grid Γ) (hΓ : IsSeparated Γ) :
    MemBMO (fun x : ℝ ↦ Real.log ‖d.G (x : ℂ)‖)
```

Its proof obtains one tuple `ε,c,C,hbd` from `generating_cell_bounds`.
The shifted bounds feed `shifted_A2_of_bounds` at exactly ε. `memBMO_log_of_A2` gives BMO of
`log ‖G(·+iε)‖²`; scalar multiplication by 1/2 and `Real.log_pow` give BMO of `log ‖G(·+iε)‖`.
Taking logarithms of the shifted and real bounds in the same `hbd` gives the off-node cell comparison
with error `|log C-log c|`. The established local integrability of the logarithm of an entire function
and `memBMO_boundary_log_of_cell_comparison` finish the literal `FF.MemBMO` statement.
No independently chosen heights are equated, and no extra analytic hypothesis is introduced.
